# Diagnostic Workbench

A vehicle diagnostics project combining a Windows desktop application, a native C++ engine, and a web management panel.

Built with Electron, React, TypeScript, C++, Node-API, Cloudflare Workers, D1 and Better Auth.

**[View the web portfolio](https://brknl28.github.io/diagnostic/)**

This repository hosts the generated web portfolio. It is not the main source repository; the application source remains private. The public interface uses sample data and does not connect to production services.

The project is under development and testing. The diagnostic engine currently uses synthetic vehicle data; physical CAN integration and a public desktop release are not available. More documentation will be added when the project is complete.
